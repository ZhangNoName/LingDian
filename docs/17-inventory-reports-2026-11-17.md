# 库存损耗、区间报表与 Review · 2026-11-17

## 产品流程

库存台账已有预警、入库、出库和盘点，但历史只能逐页浏览和导出。本轮补齐“登记损耗 → 按日期查变动 → 核对收支 → 导出完整报表”的经营流程。继续使用当前商家门店上下文，未开放跨店汇总。

- 调整方式新增“损耗”，填写数量和原因；拒绝零/负数量、超库存或旧版本，沿用请求幂等和事务流水。
- 变动记录新增起止日期、操作类型和名称/编码筛选，支持单原料追溯。原有 API 不传日期时仍可查询全部历史；Web 默认最近 30 个本地自然日。
- 新增“收支报表”页签，按原料和固定单位展示期初、入库、出库、损耗、盘盈、盘亏、期末及记录数，并可进入同原料、同期间的明细。
- 简体中文/英文文案、数字格式、日期时区说明；手机上固定显示期末列，宽表只在容器内滚动。
- 库存清单和流水仍提供当前页 CSV；收支报表提供完整快照 CSV，不受表格页码影响。

## 分析与实现约定

分析任务是逐原料核对存量与流量，采用语义 HTML 表格，不新增图表依赖。一个页面一次显示一个门店、一个期间，表格每页 20 行，报表内最多 10,000 行留在当前快照中。主要视觉编码是直接数量与固定单位，告警颜色沿用库存清单，报表不添加无业务含义的颜色/动效。

平衡口径：

`期初 + 入库 − 出库 − 损耗 + 盘盈 − 盘亏 = 期末`

- API 范围为 `[startAt, endAt)`，日期必须是含时区的 ISO 时刻；日期反向、缺少报表边界或跨度大于 366 天拒绝。
- Web 的结束日期包含当天，转换为下一本地日零点的排他边界。链接保存规范化 UTC 时刻，因此刷新/分享保留同一时间范围；界面显示浏览器时区和精确边界，CSV 记录原始 ISO 边界。
- 期初、期末按边界前的流水净变动重建，不用当前库存冒充历史值。初始建档库存为零，无流水原料显示零；结束后建档的原料不纳入期间。
- 入库、出库、损耗分别聚合金额无关的数量；盘点只聚合实际差额，分为盘盈/盘亏。阈值变更不移动库存，但计入记录数。
- 不把 kg、L、袋或不同原料相加，不提供混合数量总计；无成本单价时不虚构库存金额或损耗率。
- 原料读取及流水聚合在同一 RepeatableRead 事务内执行。聚合使用绑定参数，明确过滤 storeId 和当前原料集合。
- 支持最多 10,000 种原料和安全整数精度内的汇总，超限返回 `inventory.reportTooLarge`，不返回看似完整的截断结果；可使用原料筛选缩小范围。超大规模异步导出尚未实现。

## 状态与导出

`view`、`startAt`、`endAt`、`keyword`、`itemId`、`kind`、`page` 由 URL 表达；非法/旧链接归一化为有效默认范围，表单草稿不写入 URL。门店身份沿用已授权选择器，不从报表链接授予权限。

查询后翻报表页只裁剪已获取的快照，不逐页重新汇总。CSV 导出全部快照行，包含门店、筛选、时区、边界、生成时间、单位及平衡公式。更改表单但未查询时显示提示、禁用导出和翻页，避免把旧数据当成新条件结果；读取失败也不允许导出旧快照。重新查询会生成新快照，范围内后续登记不会静默改变已生成结果。

## 验证与限制

- 服务测试覆盖损耗扣减、幂等、零损耗/超库存拒绝；DTO 覆盖显式时区、必要边界和操作类型。
- 报表测试用 Node 内置 SQLite 执行实际参数化聚合 SQL（注册 GREATEST 对应函数），验证起始包含、结束排除、期初/期末、盘点正负差、阈值不移库、不同单位、无流水、门店隔离、带引号原料 ID 的参数绑定及超限拒绝。
- SQLite 验证的是聚合语义，不是 MySQL 驱动、数据库迁移或真实并发验收。本机仍没有隔离 MySQL/MariaDB；发布前继续要求隔离数据库验证，不能把此项算作已关闭。
- Web 测试覆盖日期转换/非法自然日、URL 状态往返/归一化、请求参数编码、完整报表不分页及 CSV 公式保护。
- 浏览器使用双店 API 测试数据，验证损耗登记、历史筛选、翻页不重取快照、20 行视图导出全部 41 行、未应用筛选的导出锁、链接刷新恢复、英文与 390px 布局、错误状态。截图只用于本地 QA，不是生产数据证明。
- `pnpm test`：638 项通过，1 项因缺少 Docker Compose v2 跳过；`pnpm run type-check`、`pnpm run build` 和 `git diff --check` 通过。最后的契约/手机布局微调后再次通过 Web 测试（86 项）、Web 构建、全仓类型检查和浏览器回归。文档链接检查通过；构建仍有既有上游工具链非阻断警告。
- 本轮不新增数据库表或迁移；LOSS 使用既有 kind 字符串字段。上线需成套更新共享契约、API 和 Web。
