# 商家分类维护 · 2026-11-18

## 日常操作

商品页增加“分类管理”，在当前授权门店查找、新建和编辑分类。分类列表每页 50 条，展示菜单排序、展示状态、店内商品总数及已发布数量；支持空结果、失败重试、翻页与手机卡片。保存后按该分类名称重新定位，避免改名或调整排序后找不到。新增分类仍默认展示且排序为 0，保留商品建档中的快速新建分类入口。

编辑可维护名称、菜单排序和顾客菜单展示。排序数值较小优先，相同值仍按创建时间。隐藏或恢复展示先说明影响与本次查询中的已发布商品数量，再单独确认。隐藏仅从顾客菜单移除分类/商品，不改变商品状态、已有订单、SKU 或配方；如需停止销售，使用商品下架。恢复后已发布商品会重新出现在菜单，不承诺原料充足。

未保存修改关闭/返回前可继续编辑或明确放弃。保存期间禁用重复提交与关闭；重名、旧版本和网络失败保留字段。旧服务缺少分类版本时编辑拒绝提交，缺少统计时显示破折号。表单、说明、错误和手机布局提供中英文，复用现有 Dialog 与表单样式。

## 版本、审计与租户范围

新增分类 version，商家修改必须提交 expected_version。更新先验证 signed merchant/store scope，锁定当前门店行（复用商家分类创建锁），以版本条件认领分类，再读取锁定后的资料、校验名称并写入。版本/名称/排序/展示和审计同事务提交；错误或审计写入失败全部回滚，不消耗版本。

改名时按数据库同店名称相等规则拒绝重名，包含隐藏分类；商家改名和新建同名分类串行化，防止两条商家路径产生新重名。数据库无强制唯一名称索引，旧平台接口仍保留历史兼容，可能存在或产生旧重名；保留原名称时允许维护这类分类的排序和展示。旧平台分类修改递增版本，使商家旧草稿失效；旧平台路径不在本轮改成细粒度授权或强制携带版本。

分类列表在一个 RepeatableRead 快照中读取分页、总数和商品计数，商品关联也显式过滤当前门店。顾客菜单原有分类→商品读取新增 product.storeId 条件；即使旧数据存在分类和商品门店不一致的单列关联，也不会把其他店商品计入当前分类或显示到菜单。此项不重写旧数据，不扩大跨店读取范围。

商家 API 新增 `PATCH merchant/stores/:storeId/categories/:id`，名称最多 120 字、排序整数 0–1,000,000、明确布尔展示状态和非负版本。类别路径/请求体不能声明其他门店。详情中的分类选择仍保留选中对象和分页查找含义，商品价格、状态和配置版本不被分类编辑改写。
