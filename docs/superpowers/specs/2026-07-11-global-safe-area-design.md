# 全局顶部安全边界设计

## 目标

让 uni-app 微信小程序的所有页面都从状态栏安全区下方开始渲染，不再由页面或导航组件分别处理顶部避让。

## 方案

- `Layout` 成为唯一的顶部安全区所有者：内容容器使用 `padding-top: env(safe-area-inset-top)`。
- `Layout` 提供 `showTabBar` 属性。首页、点单、订单、我的保留底部 TabBar；商品详情、结算、订单详情复用 Layout 并关闭 TabBar。
- `AppNavBar` 移除自身的 `safe-area-inset-top`，只负责导航行布局。
- 首页移除局部顶部安全区，避免与 Layout 叠加。

## 边界

- 不改变页面路由、数据请求、订单或购物车逻辑。
- 固定底部操作区继续保留现有底部安全区处理。
- 所有页面必须直接或间接使用 `Layout`，不允许页面自行添加顶部状态栏避让。

## 验收

- 所有七个页面均通过 Layout 渲染。
- 顶部安全区仅在 Layout 中出现一次。
- 微信小程序类型检查和生产构建成功。
