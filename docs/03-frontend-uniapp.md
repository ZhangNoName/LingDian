# 前台：uni-app

本文档文件名沿用 `03-frontend-uniapp.md`；仓库内实际工程目录为 **`uniapp/`**。

## 工程位置

`uniapp/`（使用 HBuilderX 或 CLI 创建 uni-app 项目后，将代码置于此目录，或在此目录执行官方脚手架）。

## 约定建议

1. **目录**：按功能模块划分 `pages/`、`components/`、`stores/`（如用 Pinia）、`api/`（封装 HTTP）、`static/`。
2. **请求**：统一 baseURL，从环境变量或 `manifest` / 自定义配置读取；错误与 401 集中处理。
3. **多端差异**：条件编译（`#ifdef`）仅用于平台差异，业务逻辑尽量共用。
4. **与后端联调**：开发期可使用代理或直连后端开发机；生产域名与 HTTPS 在发布配置中区分。

## 初始化参考（CLI）

在 `uniapp` 内可使用官方文档推荐的 `vue-cli` 或 `Vite + uni-app` 模板创建项目，创建完成后将生成文件纳入本仓库。

## 用户协议与隐私政策上线检查

当前小程序消费者端运营主体为“开封市示范区赵美红小吃店”。《用户服务协议》和《隐私政策》的当前版本均为 `2026-11-23`。服务端同时支持仍在使用的 `2026-08-17` 版本，按用户实际同意的版本留存记录。

### 发布前必做项

1. 在部署应用版本前，执行并确认数据库迁移 `20260817_user_legal_consents` 已部署。该迁移创建用户协议同意记录，不能仅依赖客户端勾选状态替代服务端留存。
2. 运营方核验协议中的经营主体、统一社会信用代码、经营地址、食品小经营店登记证信息及实际数据处理流程，确认客服电话可以受理监护人、隐私权利和账户注销请求，并完成法律审核。按照各类数据的用途与法定期限落实保留、删除或匿名化。运营设置目前尚无统一的自动到期清理周期。
3. 在微信小程序后台单独维护《用户隐私保护指引》，并逐项与实际代码和协议保持一致：手机号用于微信快速登录、账户识别和配送联系；微信身份用于微信登录及账号识别；头像和昵称用于用户资料展示；收货人、电话和收货地址用于地址簿与配送履约；订单用途包括点餐、履约、售后及订单查询。应用内协议不能替代平台侧配置。
4. 将 `uniapp/dist/build/mp-weixin` 导入微信开发者工具完成基础检查后，还必须以体验版在真实设备上验收协议阅读、返回状态、未勾选协议时的登录拦截、勾选后的微信手机号授权，以及微信隐私弹窗。开发者工具不能替代真机授权和隐私弹窗验收。

### 协议版本同步清单

协议版本发生变化时，发布前逐项确认：

- [ ] 先部署同时接受新旧协议版本的服务端，再上传新版小程序；
- [ ] 客户端协议版本常量已更新；
- [ ] 服务端协议版本常量已更新；
- [ ] 《用户服务协议》正文版本和发布日期已同步更新；
- [ ] 《隐私政策》正文版本和发布日期已同步更新；
- [ ] 运营方已确认新版本文本、实际处理活动和微信后台隐私指引一致；
- [ ] 小程序新版本已通过真机回归，并确认旧版本会收到更新提示。

### 服务端配置

API 部署环境必须配置与 `uniapp/src/manifest.json` 中小程序 AppID 一致的凭据：

```dotenv
WECHAT_MINI_APP_ID=wxxxxxxxxxxxxxxxxx
WECHAT_MINI_APP_SECRET=<仅保存在服务端密钥系统>
```

不要把 AppSecret、微信 access token、openid 或 unionid 写入小程序包、浏览器环境变量或可读日志。生产部署先执行：

```bash
corepack pnpm run db:migrate:deploy
```

迁移会增加用户头像字段、`user_addresses` 地址表和订单 `deliveryAddress` 快照字段。头像只接受 JPEG、PNG、WebP，最大 512 KiB。

### 微信公众平台配置

在小程序管理后台维护与实际代码一致的《用户隐私保护指引》，说明以下数据的用途：

- 手机号：微信快速登录、账户识别和配送联系；
- 昵称与头像：用户资料展示；
- 收货人、电话和收货地址：地址簿与配送履约。

在微信小程序后台维护相应的隐私指引。拒绝微信手机号授权时仍可浏览商品，登录和下单需要完成手机号授权。配送使用用户手动保存并选定的地址，门店自取无需收货地址。

### 构建与验收

```bash
corepack pnpm --filter @lingdian/uniapp test
corepack pnpm --filter @lingdian/uniapp type-check
corepack pnpm --filter @lingdian/uniapp build:mp-weixin
```

将 `uniapp/dist/build/mp-weixin` 导入微信开发者工具，并使用真实开发者或体验账号验收：

1. 同意微信手机号后可直接登录，取消授权后可返回并继续浏览；
2. `chooseAvatar` 选择的头像和 `nickname` 输入的昵称刷新后仍保留；
3. 用户可以手动新建收货地址，在小程序选择省、市、区县、街道或乡镇，并填写详细地址。首个地址自动标记为默认地址，可在地址管理切换默认与删除；
4. 自取订单无需地址，配送订单必须由用户选定本单的收货地址后才能提交；
5. 配送订单成功后，历史订单地址不随地址簿删除或修改而变化；
6. 结算页显示线下应付金额。下单后顾客线下付款，由门店确认收款。小程序不支持线上支付。生产环境使用 `ORDER_PAYMENT_REQUIRED=true`。

开发者工具不能完整替代真机授权与隐私弹窗验证，上线前至少完成一次体验版真机回归。
