# 库存损耗与盘点分析 · 2026-11-18

## 操作流程

库存管理 → 收支报表增加“收支明细 / 损耗与盘点分析”切换，复用当前门店、日期、原料和关键词筛选。分析显示完整快照内的原料数、有登记损耗的原料数和有盘点差异的原料数；数量仍按每种原料与单位展示，不合计 kg、L、袋等不同量纲。

可筛选全部、有登记损耗、有盘点差异的原料，并按编码或登记损耗率降序查看；每页 20 行。桌面保留可横向滚动的数值表，手机使用带字段名和单位的卡片。筛选、排序、页码及选中原料保存在 URL，刷新和浏览器返回可恢复。超出结果范围的页码通过替换导航收敛，避免返回时循环追加无效页面。

“查看分析”展开单种原料的期初、期末、盘点净差及登记损耗率，以及入库、出库、登记损耗、盘盈、盘亏五项横向条形。每条直接显示数值与单位，从零起算，长度只在该原料内部比较。提供出库、损耗、盘点记录按钮，携带原料、原查询范围和类型进入既有流水；流水仍可追溯采购单或盘点单。

未应用的日期或关键词修改会禁用分析筛选、排序、选中、流水跳转和导出，避免导出旧筛选或丢失表单草稿。查询失败、空数据、无匹配结果、失效原料选择及精度溢出都有明确反馈。切店清除选中的原料，页面按门店重新挂载并读取授权范围内的数据。

## 口径

- 出库与登记损耗 = ISSUE + LOSS。出库包含人工出库和销售扣料，不等于销量、营业额或生产产量。
- 登记损耗率 = LOSS ÷（ISSUE + LOSS）。分母为零显示“—”，不伪造 0%；正值不足 0.01% 显示“<0.01%”，导出保留实际比例的百分数数值。
- 盘点净差 = 盘盈 − 盘亏。盘盈和盘亏均保留；即使净差为零，也可能有两类差异。盘亏不自动归因为登记损耗。
- 期末是所选时间范围的历史账面余额，不是当前可用库存、未来供货能力或成本估值。
- 顶部三项原料数来自当前完整报表快照，不随分析范围筛选改变；不会累计不同原料的数量或平均不同比例。

数量先转为三位小数的安全整数再派生相加/相减，超出安全精度则拒绝展示和导出分析，不静默返回舍入后的假值。既有服务端报表仍限制 366 天与 10,000 种原料，超限报错。

## 快照、导出与范围

本轮不增加后端查询或数据库迁移。前端派生现有 `InventoryPeriodReport`；门店 scope、参数化 SQL、原料历史余额及 RepeatableRead 快照继续由既有库存报表服务提供。切换收支/分析、分析筛选、排序、选中原料和客户端分页不会再次请求报表；重新查询才更新快照。

CSV 导出当前分析筛选和排序后的全部行，与可见页无关。选中原料只展开详情，不缩小导出范围；原查询的单原料筛选仍有效。元数据包含门店名称/ID、明确起止时刻、时区、快照生成时间、关键词、原料筛选、分析范围、排序和公式口径。所有原始余额、流入流出、独立盘盈盘亏、派生数值及流水数一并导出，复用既有 CSV 公式注入防护。

复核同时修复两处区间问题：仅编辑关键词或流水类型时保留链接中的精确时刻，只有日期发生变化才重新生成本地零点边界；规范化导航比较解码后的 query 值，避免等价的 URL 编码导致路由拒绝重复导航后页面停留在加载态。所有追查保持左闭右开区间。

## 界面与可访问性

Vue 管理派生数据、URL 状态、表格和原生 DOM 条形；没有新增图表库。一次只绘制一张图和五个条形，最多处理既有快照的 10,000 行，列表仅显示 20 行。数量使用真实比例和直接标签，颜色只作辅助，不依赖悬浮、动画或装饰表达事实。

完整表格/手机卡片及 CSV 是图形的数值替代。条形轨道对辅助技术隐藏，标签、数值、单位与口径仍可读取；按钮有原料名称，表头有范围，筛选可用键盘操作。打开详情聚焦标题，清除详情后回到原按钮或分析范围；没有自动播放或运动效果。中英文静态文案通过同一键集合约束，原料名称/单位保留业务数据。
